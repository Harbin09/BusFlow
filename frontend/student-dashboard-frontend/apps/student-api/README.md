# Student API (`apps/student-api`)

## Responsibilities

Mobile-optimized API serving the Student Portal:

- **Live Bus Tracking**: Real-time position streams of student's assigned bus.
- **ETA Tracking**: Accurate arrival predictions for assigned pickup/dropoff stops.
- **Missed Bus Management**: Self-service report & alternative route recommendations.
- **Bus Switching**: Requesting bus switches (enforces 5 credits/month limit via Rule Engine).
- **Dynamic Pickup Updates**: Requesting temporary stop changes.
- **Notifications**: Push notifications for route changes, delay alerts, ETAs.
- **Issue Reporting**: Submitting tickets regarding drivers, bus comfort, or delays.
- **Trip History & Profile**: Historical boarding timestamps, remaining monthly credits.
