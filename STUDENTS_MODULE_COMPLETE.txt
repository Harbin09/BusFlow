HOW TO USE
================================================================================

1. VIEW THE PAGE
   $ npm run dev
   $ Visit http://localhost:3000/admin/students

2. TEST WITH MOCK DATA
   - 6 sample students loaded
   - All features work immediately
   - No backend required

3. CONNECT TO BACKEND
   - Ensure 4 endpoints are implemented
   - Update NEXT_PUBLIC_API_URL in .env.local
   - Page automatically uses real data

4. UPLOAD CSV
   - Click "📤 Upload CSV" button
   - Drag CSV file onto modal (or click select)
   - Wait for upload confirmation
   - Table auto-refreshes

5. MANAGE STUDENTS
   - Click ⋮ on any row
   - Select "Activate/Deactivate" or "Deregister"
   - Confirm action
   - Student status updates

6. SEARCH STUDENTS
   - Type in search box
   - Results filter in real-time
   - Shows matching students
   - Clear to see all
