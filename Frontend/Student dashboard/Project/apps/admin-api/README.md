# Admin API (`apps/admin-api`)

## Responsibilities

Provides administration endpoints for system managers and transport coordinators:

- **Fleet Management**: Bus CRUD, maintenance scheduling, bus-driver assignment.
- **Route Management**: Base route definitions, stop sequencing, geo-fence definitions.
- **Dynamic Route Overrides**: Creating temporary route diversions with expiration TTL.
- **Student & Driver Management**: Profiles, permissions, assignment history.
- **Capacity Management**: Setting capacity limits and reviewing utilization alerts.
- **Analytics Dashboard**: Fleet punctuality, missed bus metrics, route load factors.
- **Weather & Traffic Management**: Manual/automated environmental alerts.
- **Issue Resolution**: Triaging student/driver issue reports.
- **Live Fleet Overview**: Monitoring real-time positions of all active buses.
