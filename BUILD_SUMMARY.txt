DEVELOPMENT WORKFLOW
================================================================================

TO CREATE A NEW ADMIN PAGE:
   1. Create folder: app/admin/page-name/
   2. Add file: app/admin/page-name/page.tsx
   3. Layout automatically applies sidebar + top nav
   4. Import API helpers: import { fleetApi } from '@/lib/api'

TO USE API ENDPOINTS:
   import { fleetApi, studentsApi, etc } from '@/lib/api'

   const response = await fleetApi.listBuses()
   if (response.error) {
     console.log('Error:', response.error)
   } else {
     console.log('Data:', response.data)
   }

TO CUSTOMIZE SIDEBAR:
   Edit: app/admin/layout.tsx
   Find: navLinks array
   Add/remove items with { label, href, icon }

TO CUSTOMIZE STYLING:
   • Global styles: app/globals.css
   • Theme config: tailwind.config.js
   • Component styles: Use Tailwind utility classes

================================================================================
TROUBLESHOOTING
================================================================================

Q: "Cannot find module '@/lib/api'"
A: Check tsconfig.json has path alias. Restart dev server.

Q: "API connection failed"
A: Backend may not be running. Check NEXT_PUBLIC_API_URL in .env.local.
   Fallback demo data will still display.

Q: "Sidebar not showing"
A: Ensure you're on /admin route. Check layout.tsx exists.

Q: "Styles not loading"
A: Run "npm install". Restart dev server. Check globals.css exists.

Q: "Port 3000 already in use"
A: npm run dev -- -p 3001 (use different port)
