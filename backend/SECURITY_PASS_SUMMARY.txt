================================================================================
ERROR HANDLING
================================================================================

401 Unauthorized
  Cause: Missing or invalid JWT token
  Response: "Invalid or missing authentication token"

403 Forbidden (Role)
  Cause: User role doesn't match @Roles()
  Response: "This endpoint requires one of these roles: STUDENT"

403 Forbidden (Data)
  Cause: User tries to access other user's data
  Response: "You are not assigned to this trip"
